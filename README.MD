<center><p style="text-align: center;">With this fully automated and configurable mod, you can craft stairs back into full blocks. Allowing you to recycle stairs you no longer need. These recipes can be generated automatically by scanning for stair shape recipes, or you can configure them yourself.</p>
<p style="text-align: center;"><img src="https://i.imgur.com/QsMZSIL.png"/></p></center>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/betterstairscrafting.json</code> in your profile folder. Please note that any changes will require restarting Minecraft to take effect.</p>
<center><p style="text-align: center;"><p style="text-align: center;"><b>block_amount</b> - determines how many blocks you get from crafting</p>
<p style="text-align: center;"><p style="text-align: center;"><b>add_recipes_manually</b> - if set to true, this mod stops generating these recipes automatically and generates them based on the list bellow</p>
<p style="text-align: center;"><p style="text-align: center;"><b>block_stairs_list</b> - list of stairs and the corresponding blocks you craft from them</p></center>
</details>
